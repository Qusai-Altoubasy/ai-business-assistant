# AI Business Assistant

A learning-oriented full-stack AI chat application. The backend exposes a
Quarkus REST API backed by a declarative LangChain4j service and the Gemini
Developer API, while the Flutter client provides a desktop-first chat
experience for Web and Linux.

## Tech stack

- Java 21 and Quarkus 3.39
- Quarkus LangChain4j and Google Gemini
- Flutter 3.44 and Dart 3.12
- Riverpod and Dio
- Docker Compose for the local demo environment

## Requirements

- JDK 21 or later
- Flutter stable
- Chrome for Flutter Web, or the Linux desktop toolchain
- A Gemini Developer API key for AI requests

Maven does not need to be installed because the backend includes the Maven
Wrapper.

## Configuration

The backend reads these environment variables:

| Variable | Required | Description |
| --- | --- | --- |
| `GEMINI_API_KEY` | Yes | Gemini Developer API key |
| `GEMINI_MODEL` | Yes | Gemini chat model ID |
| `FRONTEND_ORIGIN` | No | Browser origin allowed by CORS; defaults to `http://127.0.0.1:3000` |

Create the local backend configuration:

```bash
cd Backend
cp .env.example .env
```

Replace the placeholder API key in `Backend/.env`. The `.env` file is ignored
by Git and must never be committed.

The frontend reads `API_BASE_URL` at build time through `--dart-define`. It
defaults to `http://localhost:8080`.

## Run locally

Start the backend from one terminal:

```bash
cd Backend
./mvnw quarkus:dev
```

Start the Flutter Web client from another terminal. The hostname and port match
the backend's default CORS origin:

```bash
cd Frontend
flutter pub get
flutter run -d chrome \
  --web-hostname 127.0.0.1 \
  --web-port 3000 \
  --dart-define=API_BASE_URL=http://127.0.0.1:8080
```

For Linux desktop:

```bash
cd Frontend
flutter run -d linux \
  --dart-define=API_BASE_URL=http://127.0.0.1:8080
```

## API endpoints

The deterministic endpoint does not call Gemini:

```bash
curl http://127.0.0.1:8080/hello
```

```text
Hello World
```

The AI-powered endpoint returns a plain-text response generated by Gemini:

```bash
curl http://127.0.0.1:8080/hello/ai/Quarkus
```

The response varies by model. Calling this endpoint sends the supplied path
value to Gemini and may incur API usage costs.

## Verification

Run the backend tests:

```bash
cd Backend
./mvnw test
```

Analyze and test the frontend:

```bash
cd Frontend
flutter analyze
flutter test
```

## Docker Compose

The [`deploy`](deploy/README.md) directory contains the local two-service
Compose configuration and its environment template.

> **Note:** The Compose configuration expects both `Backend/Dockerfile` and
> `Frontend/Dockerfile`. Merge or add the backend container files before
> starting the complete stack.

## Project structure

```text
.
├── Backend/                 # Quarkus REST API and Gemini service
├── Frontend/                # Flutter Web and Linux chat client
├── deploy/                  # Local Docker Compose configuration
├── .gitignore
└── README.md
```

The current product scope is intentionally small: one deterministic health-like
endpoint and one AI greeting/chat endpoint. Navigation items for analytics,
knowledge, data sources, tools, evaluation, and settings are placeholders for
future capabilities.
